# Lumen Desk

Stripe demo shop for electronics and desk setup — catalog, cart, and checkout with webhooks for orders.

## Stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **Drizzle ORM** + **Neon Postgres**
- **Stripe Checkout** + webhooks

## Features

- Catalog with search and filters
- Cart persisted in `localStorage`
- Checkout via Stripe Checkout
- `checkout.session.completed` webhook → saves orders to the database
- Lean admin with login and order filters

## Local setup

```bash
git clone <repo-url>
cd stripe-shop
npm i
cp .env.example .env.local
```

Fill in the variables in `.env.local` (see the table below), then:

```bash
npm run db:push
npm run db:seed
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

> **Note (Windows):** the `dev` and `build` scripts use `--webpack`. On some Windows setups, Application Control / SWC can fail without that flag.

## Environment variables

| Variable | Purpose |
|---|---|
| `DATABASE_URL` | Neon connection string (runtime / pooled) |
| `DATABASE_URL_UNPOOLED` | Neon connection string without pool (Drizzle Kit / migrations) |
| `STRIPE_SECRET_KEY` | Stripe API secret key (`sk_test_…` / `sk_live_…`) |
| `STRIPE_WEBHOOK_SECRET` | Webhook endpoint secret (`whsec_…`) |
| `NEXT_PUBLIC_APP_URL` | Public app URL (e.g. `http://localhost:3000`) — used for Checkout redirects |
| `ADMIN_PASSWORD` | Admin panel password |
| `ADMIN_SESSION_SECRET` | Secret for signing the admin session cookie |

Optional: `NEXT_PUBLIC_SITE_URL` (metadataBase / OG; falls back to `http://localhost:3000`).

**Do not** put real secrets in the repository — use `.env.local` (already in `.gitignore`).

## Local webhooks (Stripe CLI)

In another terminal:

```bash
stripe listen --events checkout.session.completed --forward-to localhost:3000/api/webhooks/stripe
```

Copy the `whsec_…` generated by the CLI into `STRIPE_WEBHOOK_SECRET` in `.env.local` and restart `npm run dev` if needed.

## Test payment

Stripe test card:

- Number: `4242 4242 4242 4242`
- Expiry: any future date
- CVC: any 3 digits

Use **test** mode in the Stripe Dashboard (`sk_test_…`).

## Admin

- Login: `/admin/login` (password = `ADMIN_PASSWORD`)
- Orders: `/admin/orders`

## Deploy

1. Deploy to **Vercel** (or similar).
2. Configure the **same** environment variables in the host panel.
3. In the Stripe Dashboard, create a webhook pointing to:

   `https://YOUR_DOMAIN/api/webhooks/stripe`

   Event: `checkout.session.completed`.

4. Put the production `whsec_…` in `STRIPE_WEBHOOK_SECRET` and update `NEXT_PUBLIC_APP_URL` to the public domain.

## Out of scope

Buyer accounts, inventory CRM, physical shipping, full transactional email, multi-store, etc. This project is a portfolio demo focused on catalog + Checkout + webhook → orders + light admin.
